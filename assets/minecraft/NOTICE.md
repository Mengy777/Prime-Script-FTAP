# Minecraft reference textures

Steve and diamond sword texture artwork: Mojang Studios / Microsoft, Minecraft Java Edition.
Reference files retrieved from the Minecraft asset mirror, version1.21.5:
- https://raw.githubusercontent.com/InventivetalentDev/minecraft-assets/1.21.5/assets/minecraft/textures/entity/player/wide/steve.png
- https://raw.githubusercontent.com/InventivetalentDev/minecraft-assets/1.21.5/assets/minecraft/textures/item/diamond_sword.png

MinecraftAssets.lua encodes only the right-arm UV faces and sword pixels for local rendering. No runtime image downloads or paid features are involved. Not affiliated with or endorsed by Mojang/Microsoft; artwork is not claimed as our original or as CC0.
