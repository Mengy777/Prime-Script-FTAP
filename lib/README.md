# UI dependencies

- `Obsidian.lua`: the Library module extracted from the Resonance source fetched on 2026-10-24: https://github.com/aslan90101/resonance/blob/main/Resonanse.lua . Based on Obsidian by deividcomsono; MIT license is included. Prime Visuals changes only the compact header layout so the brand remains visible next to its icon.
- `Icons.lua`: the same embedded Lucide module used by that source. Icon sprites are provided by mstudio45/lucide-roblox-direct. Lucide license is included.

Only the UI modules are used. Resonance Main, Bootstrap and the top-level Infinite Yield loader are not loaded.
