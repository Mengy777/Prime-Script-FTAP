# Prime Vortex — Changelog

## 0.2.2 — Защищённый запуск · 2026-10-25

- Повторные попытки HTTP/компиляции и защита ранней загрузки Obsidian.
- Сбой необязательной иллюстрации оставляет окно рабочим; частичные GUI-элементы удаляются.
- Обязательная ошибка завершает запуск с очисткой ввода, GUI, событий и контроллера; приватная библиотека не затрагивает Visuals. Отменённый запуск не выдаёт ложное сообщение об ошибке.
- Стиль, изображения и набор функций не менялись.

## 0.2.1 — Static PNG preview · 2026-10-25

- Большой демон — исходный PNG с GitHub без анимации, цветных слоёв и контурной подмены.
- Прозрачность изображения больше не блокируется ожиданием IsLoaded; добавлены HTTP fallback и свежий ключ локального кэша.
- В шапке — отдельный лаконичный красный вихрь с вращением, без радужной смены цвета. Декоративные игровые функции не добавлялись.

## 0.2.0 — Demon preview · 2026-10-25

- Вместо увеличенной стандартной иконки огня добавлена оригинальная прозрачная иллюстрация рогатого демона 1254×1254 и её версия в заголовке.
- Цветной диагональный блик, мягкий спектральный контур и аура; чёрно-красная палитра меню и декоративные угольки сохранены.
- Версионный кэш PNG, ожидание IsLoaded без блокировки интерфейса, собственный нативный контур при отсутствии API, очистка обработчиков и защита от позднего ответа после закрытия.
- Vortex остаётся UI-оболочкой без игровых функций. Запуск по прежнему отдельному loader или из Settings Prime Visuals.

## 0.1.0 — Rage UI · 2026-10-25

- Отдельная оболочка на Obsidian: чёрно-красная палитра, эмблема пламени, мягкое пульсирующее свечение и декоративные угольки.
- Одно пустое содержимое без игровых функций, переключателей, фальшивых категорий и поиска.
- Перемещение штатной шапкой, скрытие/открытие Right Ctrl, полная выгрузка крестиком внутри окна. Повторный запуск заменяет только Vortex.
- Приватный экземпляр Obsidian не перезаписывает глобальный Library от Prime Visuals. Игровые объекты, камера и освещение не изменяются.
