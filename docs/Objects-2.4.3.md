# ESP предметов 2.4.3

Пользователь2026-11-02 засчитал9 предыдущих пунктов ESP объектов работающими, затем запросил объединение настроек. Это одобрение старого поведения, не последующей переработки.

Новая подстраница ESP/Предметы содержит один master. Настройки — три страницы: Типы, Оформление, Цвета. Blobman/Gucci, предметы защиты (Shuriken/Kunai/Plate/Pickaxe/Pallet) и боевые (Banana/Snowball/Shuriken/Kunai/Pickaxe) используют прежние правила поиска и настройки категорий. Типы группируются по назначению; сюрикен/кунай/кирка могут относиться к обеим категориям. Существовавшее исключение BananaPeel и вложенных Model не изменено.

Master-off очищает эти маркеры и не стирает выбор. Самоподсветка и Reveal invisible не подчиняются master. Фильтр Other players only относится к категории предметов защиты, как раньше. Общая дальность применяется к трём категориям, highlight можно выключить при включённых подписях; иконки исходных asset ID доступны для боевых предметов. Блобманы и защитные предметы получают подписи без выдуманных иконок. Для собственного item color/rainbow следует отключить исходную палитру предметов.

15 новых ключей,351 всего. applyProfile выводит master из blobESP/antiKickESP/combatESP только для старого payload без objectESPEnabled. Проверено холодное восстановление master=false при сохранённых категориях и миграция старого профиля. Никаких новых игровых remotes/состояний персонажа.

Проверки: Luau-компиляция,23 сценария83 группы, visual_expansion (master/type filters/style/color) и object_profiles (persistence/migration). Реальные ассеты, дальность/подписи и popup UX требуют пользовательской проверки.
