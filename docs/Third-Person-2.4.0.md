# Исчезновение тела — 2.4.0, 2026-11-01

Повторный пользовательский отчёт: через несколько минут без респавна виден только face decal, после ресета аватар восстанавливается. Предыдущие локальные-множительные фиксы не решили проблему.

Статически просмотрены записи Transparency/LTM в main, VisualExpansion и AntiKick: thirdBody/thirdNear/body/freeBody, deathDust, bodyAppearance/revealInvisible, маркеры/ghost, скрытие toy и world-эффекты. DeathDust намеренно использует layered LTM, AntiKick скрывает descendants своего toy, а не весь Character. Утверждать их причиной этого отчёта оснований нет. Наблюдение face-only совместимо с обычной Transparency=1 на BasePart; это отдельный путь, ранее не покрывавшийся менеджером.

Менеджер теперь отслеживает обе прозрачности. Вдали обычная полная прозрачность восстанавливается по известной видимой исходной величине. Canonical R6/R15 тело получает fallback0, если при обнаружении уже невидимо. Неизвестным скрытым helper и изначально скрытым аксессуарам значение не угадывается. Зарегистрированные чужие эффекты Transparency сохраняют приоритет. Вблизи thirdAlpha снимается, head/accessories скрываются thirdNear. Все сигналы и слои имеют очистку.

Проверки: third_person_visibility.py содержит360 near/far циклов с2-секундными шагами модельного времени, поздние Transparency/LTM=1, аксессуар.2, поздний MeshPart.4, невидимый helper и уже скрытый canonical Torso. Прежние pitch/stale Focus/respawn/cleanup тесты сохранены. Модельное время не равно12 минутам настоящего Roblox. Компиляция и общий suite проверяются отдельно.

Ручной CAM-240 ожидается. Без захвата свойств в работающем FTAP нельзя доказать, какой игровой контроллер инициировал скрытие, или гарантировать устранение всех причин.
