# Проверка 2.1.0 / Vortex 0.2.0 · 2026-10-25

Иллюстрации созданы встроенным image_gen и скопированы без ресайза/перерисовки. Оба PNG имеют размер 1254×1254, RGBA и реально прозрачные пиксели (диапазон альфа 0–255). Контроль CRC всех PNG-чанков пройден. Анимация реализована слоями Roblox UIGradient/ImageLabel, а не уменьшенным sprite-sheet.

```text
python tests/sim/emblems.py
python tests/sim/home_start.py
python tests/sim/profiles.py
python tests/sim/stress.py
python tests/sim/esp_memory.py
python tests/sim/camera_cleanup.py
python tests/sim/write_races.py
```

Используются зависимости из tests/requirements.txt. Эмблемный тест исполняет настоящий AnimatedEmblem.lua с симулированными GUI/FS/HTTP: попадание/промах кэша, ремонт повреждённого кэша, неверный HTTP-ответ, отказ записи, отсутствие API, ожидание IsLoaded, 30 Гц, пауза при скрытии, отключение обработчиков и запрет поздней записи после выгрузки.

Home-тест подставляет конфиг 2.0 с сохранённой вкладкой Settings: запуск, загрузка слота и отмена открывают Home, FOV сохраняется. Переключение вкладок и 120 тиков UI-анимации не записывают неизменённый профиль.

Пройдены повторные конфигурационные тесты 178 параметров, восемь случайных профилей, 20 повторных запусков, тесты слотов/обмена/ошибок файлов и регрессии прежних функций. Отдельная симуляция Vortex проверяет создание, анимацию, повторный запуск, закрытие и сохранность приватного Library; запуск из Visuals заменяет устаревшую оболочку 0.1.0.

Luau-компиляция основных скриптов и библиотек пройдена. Это проверки кода и файлов, не live-рендер Roblox, не тест прав конкретного executor и не измерение GPU/FPS. Для проверки в игре: Home/шапка обоих скриптов, качество PNG и блики, повторное открытие из кэша, скрытие/закрытие, сохранность эффектов и старт Visuals на Home.
