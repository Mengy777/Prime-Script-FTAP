# Prime Visuals — Major Update 3.0.0

2026-11-02. Работа выполнена в основной ветке по уточнению пользователя. Проверенные игровые реализации сохранены, новые обязанности вынесены в отдельные UI/input-модули вместо рискованной переписи всей физики. Это не утверждение о доказанном отсутствии всех багов.

## Архитектура и аудит

- `Keybinds.lua`: один маршрутизатор ввода, захват, проверка клавиш/мыши, конфликтов, пауза при вводе текста/работе с меню, очистка. Нет обработчика на каждую функцию.
- `MajorInterface.lua`: отдельный владелец тем/HUD/биндов с ранней регистрацией cleanup до построения UI; ошибка конструктора не оставляет половину интерфейса.
- `Navigation.lua`: удалён весь код верхних переключателей, их объектов, анимаций и посредника поиска; используются родные колонки/прокрутка и поиск Obsidian. Главная не переработана.
- `PrimeIcon.lua`: геометрическая Omega из32 сегментов, без внешней картинки/загрузки ассета. Два одинаковых знака для header/HUD, вращение и единый плавный радужный цвет. Феникс Home сохранён.
- Загрузка показывает fullscreen CanvasGroup до обязательных модулей; этапы отражают реальные имена загружаемых модулей, без фальшивого процента и искусственных3–5 секунд. Плавное появление/уход. Ошибки убирают overlay.
- Loader сохраняет source cache и повторно использует проверенную чистую factory PrimeIcon при повторном создании HUD. Все зависимости runtime закреплены одним тегом3.0.0. Полностью переписать и доказать каждую реализацию игры в рамках UI-релиза не заявляется.
- Темы обновляют registry по изменению с ограничением частоты, а не каждый кадр. Метрики HUD обновляются раз в секунду. Декоративные движения не сохраняют конфиги.

## Найдено и исправлено

1. Повторные обращения к featureSettings теперь используют существующий объект через основной cache.
2. Отсутствующая возможность открыть параметры выключенной функции мешала назначить бинд до включения — добавлен явный opt-in SettingsWhenDisabled; старые синтетические/сторонние owner ведут себя прежним образом.
3. Старые назначения могли конфликтовать с новым конфигом — значения проверяются до изменения, routing очищается перед применением. Дубликаты отклоняются.
4. Отключённый штатный бинд Unknown мог совпасть с Unknown у мыши — добавлено исключение в Obsidian.
5. Применение темы не должно перетирать сохранённый цвет — пресетная палитра и собственные accent/background явно разделены.
6. Отделённое оформление Home ранее рисовало свой header — больше не передаёт Header в artwork; Omega имеет одного владельца.
7. Частичная ошибка нового конструктора очищает status GUI/input/intro через ранний cleanup.

## Бинды

121 сохраняемое назначение:120 существующих toggle-контролов и меню. По умолчанию все пустые. Настройки функции доступны через gear/ПКМ даже до включения. Кнопка «Назначить клавишу» ждёт следующий keyboard/mouse1–3; Escape отменяет, Backspace/Delete очищают. Поле показывает текущее имя клавиши. Прямой ввод также валидируется. Дубликаты запрещены; конфиги сохраняют bind_* как обычные стабильные Input-ключи. Действия-кнопки Spawn/Delete/Import не получают автоматические бинды — это не toggle-функции.

Штатные RightShift/3/F4 для переключения меню/third/freecam отменены согласно требованию пустых назначений. WASD/Space/Q, E игры, управление манекеном и контекстный ПКМ Freecam — моторное управление режимами, сохранены. Выход из Freecam всегда возможен через HUD-крестик, меню открывается нажатием watermark или маленького Omega launcher при отключённой панели. Можно назначить отдельный bind_menu и bind_freeCameraEnabled.

## Темы и экранная панель

Темы Obsidian/Midnight/Crimson/Emerald; собственные accent/background/text colors, font Builder Sans/Gotham/Roboto/Code, прозрачность фона меню. Прозрачность сохраняет текст читаемым, не делает все элементы одинаково прозрачными. Экранная панель: Omega/PRIME VISUALS, FPS, optional clock/player count, enable, opacity и vertical position. Это реальные секундные клиентские FPS, не серверные показатели. Мини-launcher предотвращает потерю доступа при отсутствии bind_menu.

## Совместимость и пределы проверки

395 сохраняемых настроек; все257 прежних ключей сохранены, добавлены121 бинд и17 UI/HUD настроек. Старые профили получают безопасные defaults. Схема1 совместима; данные проверяются, игровые эффекты не удалялись. Старые удалённые Objects/Items/Animations/Experimental не возвращаются. Отдельный PrimeVortex.lua остаётся прежним.

Проверки: реальная компиляция всех Lua-файлов через tools/compile.mjs; полный suite, actual native popup tests, profiles/stress, cold restore, failed module/partial constructor cleanup, Major3 keyboard/mouse capture/conflicts/menu pause/theme/HUD. Симуляция не является живым Roblox/FTAP renderer, не доказывает точное расположение/плавность или прирост FPS. Визуальная и игровая приёмка3.0 новая; одобрение2.4.4/главной2.4.5 не распространяется автоматически.
