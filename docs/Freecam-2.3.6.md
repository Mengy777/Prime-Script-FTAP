# Freecam 2.3.6 — 2026-10-31

Пользователь сообщил: после броска другим игроком тело перестаёт отображаться возле точки перехода, затем повторные переходы перестают работать. Предполагаемые причины из статического анализа: перенос только HRP при разделённых физических сборках и запрет по Ragdolled. Это не подтверждённая трассировка реального сервера.

Решение: один helper вычисляет дельту от HRP к целевой CFrame, применяет её через Model:PivotTo к текущему pivot модели и обнуляет линейную/угловую скорость всех её BasePart. Используется для перехода и возврата. Локальная видимость и намеренные эффекты прозрачности не переопределяются дополнительно. Серверные флаги рагдолла не меняются. Сохраняются запреты сиденья/якоря; временно заблокированный возврат можно повторить. После выключения Freecam ожидающий возврат сбрасывается.

Проверки: Luau-компиляция, tests/sim/visual_expansion.py с 12 повторениями разделённой модели и остаточного импульса, проверкой локальной видимости и Anchored-возврата. Стенд использует упрощённые трансформации, без настоящей сетевой физики.

Ручная проверка (пока НЕ подтверждена):

1. ПКМ — перейти к точке, проверить видимое тело.
2. Другой игрок бросает персонажа; проверить возврат и следующий переход после отпускания.
3. Повторить 5–10 раз, проверить отсутствие накопления невидимости/отказа перехода.
4. Выключить Freecam, проверить обычную камеру, движение; включить снова.
