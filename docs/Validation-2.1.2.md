# 2.1.2 — проверка отказов и длительной сессии

Проверки исполняют настоящий исходник скриптов и модулей с детерминированными Roblox/Obsidian/FS/HTTP фикстурами. Это не live FTAP/Xeno и не измерение FPS.

## Новые воспроизводимые проверки

```text
python tests/sim/startup_resilience.py
python tests/sim/vortex_startup.py
python tests/sim/long_session.py
python tests/sim/emblems.py
```

- HTTP: первые две попытки неудачны, третья успешна; временный HTML вместо Lua; исключение компилятора; успешный кэш повторно используется. Неудачный необязательный исходник не мешает последующей успешной попытке.
- Постоянный сбой обязательного Obsidian/ConfigStore: одно уведомление, отсутствие оставшегося GUI/эффектов, восстановление мыши и сохранность файлов конфигов.
- Runtime-ошибка после частичного создания библиотеки: один запуск тела, отслеживание частичного GUI/соединений и очистка. Неверный API/реестр сигналов не ломает аварийную очистку.
- Ошибка CreateWindow до обычной регистрации shutdown; необязательное оформление с HTTP/синтаксической/конструкторной ошибкой; удаление его частичных детей и возврат значка. Vortex сохраняет приватность Library.
- Поздний ответ после закрытия не выполняет модуль. Намеренная отмена Vortex не показывает ложный fatal-диалог. PNG восстанавливается после двух временных ошибок.
- Линия: первая GrabParts пустая; активная папка имеет то же имя; 60 замен/смертей; вложенность; позднее назначение имени; временное переименование области; поздние игровые записи Texture/TextureSpeed; радуга и ручной цвет; ограниченное число связей; шесть минут симулированных тиков; выключение и полное восстановление свойств; повторный запуск в том же состоянии Workspace без перезахода. Информация о захвате выбирает актуальный предмет.
- Двенадцать циклов принудительного удаления ColorCorrectionEffect, частиц, меша шляпы, прицела, скайбокса, облаков и ESP-контейнера; игровые сбросы FOV/дистанции. Включённые эффекты восстанавливаются без повторных записей конфига.
- Разовая ошибка callback не отключает обработчик навсегда: соблюдается пауза, следующая попытка работает, уведомления не спамятся, выгрузка останавливает обработчик.

## Остальные проверки

Пройдены Luau-компиляция обоих скриптов и библиотек, tests/sim/profiles.py, stress.py, home_start.py, camera_cleanup.py, write_races.py, esp_memory.py, а также прежние симуляции воды/фильтров, линии/ESP, радуги, ColorPicker, панелей параметров, манекенов, запуска/закрытия Vortex.

Граница покрытия: реальная игра может использовать другие имена/пути объектов или постоянно переписывать свойства своим кодом. Исправлены воспроизводимые причины и добавлено восстановление, но отсутствие всех возможных ошибок не заявляется. Пользовательская проверка: серия смертей и обычная длительная игра, изменение параметров линии, повторный запуск только скрипта и нормальное выключение эффектов.
