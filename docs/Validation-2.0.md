# Проверка Prime Visuals 2.0.0 · 2026-10-25

Проверки выполнены с реальным исходным кодом PrimeVisuals.lua и ConfigStore.lua, но с симулированными Roblox, Obsidian UI и локальными файлами. Это не запуск в FTAP/Xeno и не проверка фактического FPS или внешнего вида меню в игре.

## Воспроизведение конфигурационных тестов

Зависимость: Python и пакет из `tests/requirements.txt`. Из корня репозитория:

```text
python tests/sim/profiles.py
python tests/sim/stress.py
python tests/sim/esp_memory.py
python tests/sim/camera_cleanup.py
python tests/sim/write_races.py
```

Фикстура `roblox_fixture.py` не запускается отдельно. Она подменяет службы игры и интерфейс, а JSON кодируется/декодируется настоящим JSON-кодеком Python. Файловый адаптер инъецирует сбои; тесты не меняют реальные конфиги пользователя.

## Пройденные сценарии

- Все 178 зарегистрированных параметров проходят сериализацию, чтение и повторный запуск. Проверяются не только значения виджетов, но и применённые FOV, дистанция, текстуры неба, солнце, облака, шейдеры и вода.
- Восемь воспроизводимых случайных профилей: 1 424 варьируемых значения, включая все типы полей. Импорт, загрузка, координаты, вкладка, положения панелей, офлайн-выбор ESP и холодный повторный запуск.
- 20 повторных исполнений скрипта в одной симулированной игре: эффекты не дублируются, готовое небо не запрашивает модель повторно.
- 120 тиков анимации не создают файловых записей. 50 изменений подряд объединяются в одну запись журнала; выгрузка сохраняет последнее изменение до запланированного таймера.
- Все пять слотов, имена, повторная запись, сохранение текущего состояния после загрузки, отмена последней загрузки.
- Перенос JSON между двумя аккаунтами; раздельные автоматические настройки и слоты.
- Подтверждение перезаписи, импорта и удаления, истечение 6 секунд, смена операции без переноса подтверждения.
- Битый JSON, слишком большой файл, неизвестная схема, неверные типы, диапазоны, RGB, небо, позиции и обход папки импорта не заменяют слот.
- Изменение настройки и выгрузка во время незавершённой записи: свежий снимок не теряется. Временная ошибка диска автоматически повторяется после восстановления доступа без нового редактирования.
- UTF-8: русские названия и emoji проходят сохранение/экспорт.
- Самая новая копия с корректным JSON, но недопустимым значением настройки, отклоняется в пользу более старой полностью валидной копии.
- Повреждённая основная копия, ошибка записи, обрыв первой и второй записи, повторная попытка. При повреждении обеих автоматических копий данные не затираются простым запуском/выгрузкой.
- Полный сброс сохраняет именованные слоты и сбрасывает автоматический профиль. Сброс неба/времени остаётся сбросом на следующем сервере с другими исходными значениями.
- ESP-подборщик с поведением native Multi отбрасывает отсутствующие строки, но сохранённый выбор переживает выход/перезапуск и возвращается при появлении игрока. Ручное снятие выделения учитывается.
- FOV отдельно восстанавливается у старой и новой камеры. Ошибка callback возвращает переключатель в прежнее состояние.

Дополнительно пройдены Luau-компиляция основного скрипта и библиотек, а также регрессионные симуляции: View/RMB и дистанция, скайбокс, вода и её очистка, фильтры, частицы/FPS, устойчивость ColorPicker к сбоям, радуга, Custom Line после респавна, ESP, меню параметров, запуск Vortex, модуль манекенов и его интеграция. Физику манекенов не меняли.

## Исправления из аудита

- При смене камеры выгрузка могла присвоить новой камере исходный FOV старой: теперь исходные значения хранятся по экземплярам камеры.
- Native Multi-подборщик очищал отсутствующих игроков: теперь серверные строки отделены от сохранённого выбора.
- Программный setter мог оставить неверное состояние при ошибке callback или флаг подавления после ошибки виджета: добавлены восстановление флага и откат значения.
- Восстановление после сброса времени/солнца не должно заново применять прежние «дефолты» другого сервера или создавать сохранённое небо без активной настройки.

## Осталось проверить пользователю в игре

Холодный запуск через executor и физический перезапуск Roblox; реальная рабочая папка и права executor; восстановление собственного сложного оформления; пять слотов и отмена; обмен файлом с другом; отсутствие заметных пауз при обычной игре. Симуляции не заменяют эти проверки.
