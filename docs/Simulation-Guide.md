# Симуляции Prime Visuals

Запуск всего набора из корня репозитория:

```powershell
python tests/run_simulations.py --report docs/Simulation-report.md
```

Зависимости: Python и пакет `lupa` из `tests/requirements.txt`. Доступный в текущем рабочем окружении пакет подключается через PYTHONPATH; это локальное удобство, не требование к переносимой установке. Luau-компиляция выполняется отдельно реальным Luau-компилятором; успешный запуск Lua-модели не заменяет её.

Каждый сценарий запускается в отдельном процессе, ошибки и таймауты учитываются в общем результате. `--report` сохраняет весь вывод, включая предупреждения, а не только строки PASS. `--date` позволяет явно указать дату отчёта. Версия читается из основного файла.

## Что добавлено к стенду

- `controls_matrix.py`: все 336 сохраняемых ключей, переключения флагов, все элементы обычных списков, границы числовых настроек, изменение цветов. Поля ввода получают исходные значения; корректность/ошибки ссылок и конфигов покрывают отдельные сценарии. Действия кнопок проверяются специализированными тестами, а не автоматически нажимаются в случайном порядке.
- `server_model.py`: канонический список игроков, отдельная Lua VM, дерево объектов и файловая система каждого клиента; очередь с задержками/джиттером, сохранением порядка и поколениями подключений. Локальные экземпляры не пересылаются автоматически другим клиентам. Это заданное правило модели, а не экспериментальное доказательство сетевой семантики Roblox.
- `server_integration.py`: два клиента с реальным основным кодом, локальные эффекты, уход/возврат выбранного игрока, запоздалые сообщения старого подключения, 25 возрождений и пересозданий Beam. Реальные модули манекенов/R6 проверяются на создание, замену аватара, лимит, ошибку имени, захват/ввод вращения/дистанцию/бросок/потерю фокуса и очистку.
- Остальные сценарии: профили, конкурентные записи/повреждения, запуск/отказы модулей, камеры и Freecam, небо, освещение, снег, океан, ESP, длительная сессия, нативные UI-обработчики и изображения.

## Границы результата

Это детерминированная интеграционная модель, а не эмулятор Roblox или копия сервера FTAP. Здесь нет настоящего решателя физики, рендера, сетевого протокола Roblox, серверных исходников FTAP и его внутренних проверок. Нет доказательства доступности всех пользовательских ассетов или одинакового поведения всех executor API. Эти пункты проверяются в игре.

Два ожидаемых предупреждения в матрице показывают отсутствие API локальных изображений и нативного CameraInput в её облегчённом окружении. Проверяется безопасный fallback; успешные/отказные пути изображений и CameraInput отдельно проверяют `emblems.py` и `third_person_pan.py`. Любое иное предупреждение или неожиданное уведомление проваливает матрицу.

Предыдущие подтверждения пользователя не заменяются симуляциями. Новое оформление UI требует отдельного подтверждения в Roblox. Отчёт фиксирует выполненные сценарии и не означает «любые баги исключены».
